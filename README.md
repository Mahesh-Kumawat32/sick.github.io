# SICK // Haute Streetwear & Aesthetic Beauty

A modern, high-contrast, editorial frontend website designed for **SICK**, featuring heavyweight t-shirts, tailored shirts, avant-garde outerwear, and minimalist unisex cosmetics.

---

## ⚡ Key Features

1. **Auto-Rotating Multi-Second Image Showcase**
   - Editorial Hero Carousel that transitions high-fashion imagery every **3.5 seconds**.
   - Dynamic progress bar indicators illustrating slide duration.
   - Interactive controls: manual slide dots, previous/next arrows, and auto-pause on hover.

2. **Urgent Flash Sale & Special Offers**
   - Active real-time countdown timer down to the millisecond (`08h : 45m : 18s : 89ms`).
   - One-click clickable coupon banner (`SICK40`) that instantly applies a 40% discount across the shopping bag with toast confirmation.
   - Limited stock warning bars ("*Only 2 left at this price!*").
   - Discount badges (`-50%`, `-42%`, `FLASH DROP`).

3. **Curated Product Catalog & Categorization**
   - **T-Shirts**: Acid wash oversized tees, heavyweight boxy cuts, distressed graphic tees.
   - **Shirts**: Camp collar textured shirts, raw hem brushed utility overshirts, tailored luxury poplin.
   - **Outerwear & Apparel**: Sub-zero architectural puffers, distressed leather moto jackets, multi-pocket cargos.
   - **Beauty & Grooming**: Signature *Nocturne* unisex eau de parfum, peptide botanical serums, and peptide lip treatments.
   - Dynamic category filter buttons (*All, T-Shirts, Shirts, Outerwear & Pants, Beauty & Care, Active Offers*).

4. **Interactive Shopping Experience**
   - **Dual-Angle Hover Image Switch**: Hovering over any garment immediately flips from standard studio angle to an alternate editorial angle.
   - **Slide-out Cart Drawer**:
     - Quantity increment/decrement.
     - Dynamic subtotal, discount, and total computation.
     - Free Express Shipping progress bar ($120 threshold) with live remaining dollar amount.
   - **Quick View Modal**:
     - High-resolution zoom inspection.
     - Interactive size selection (`S`, `M`, `L`, `XL`).
     - Live stock availability indicator.
   - **Wishlist Toggle**: Heart icon with smooth animation and active status.
   - **Toast Notifications**: Floating feedback for bag updates, coupon activation, and wishlist toggles.

---

## 🚀 How to Run & Preview

Simply double-click `index.html` to open it directly in any modern web browser (Google Chrome, Microsoft Edge, Brave, Safari, Firefox).

Alternatively, serve it locally with any lightweight static server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```
Then visit `http://localhost:8000` in your browser.
